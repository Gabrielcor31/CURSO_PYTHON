# Análise de Clusters com DBSCAN

Este projeto aplica a técnica de clusterização **DBSCAN (Density-Based Spatial Clustering of Applications with Noise)** para analisar conjuntos de dados em diferentes cenários, destacando a identificação de padrões espaciais, clusters densos e pontos fora da curva (outliers).

## 📌 Objetivos

- Demonstrar o funcionamento do algoritmo DBSCAN na prática
- Explorar a influência dos parâmetros `eps` e `min_samples`
- Visualizar clusters e outliers com gráficos interativos
- Comparar DBSCAN com KMeans em certos contextos

## 📊 Tecnologias e Bibliotecas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
